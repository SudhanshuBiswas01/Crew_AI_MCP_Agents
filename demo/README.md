## What the clip covers (~5 minutes)

| Time | Content |
|---|---|
| ~1 min | The pitch — what you built and why it matters |
| ~1 min | Live run — ask a question, show tool calls, show cited answer |
| ~1.5 min | One decision + one failure — real choice + something that broke |
| ~1 min | What you learned — MCP, CrewAI, security risk, key sources |
| ~30 sec | What's next — changes before real company data |

## Recording tips

- One continuous take is fine, no editing needed.
- Keep your face or voice on; share your screen for the demo part.
- Ask one of the three questions in `examples/` so the tool calls are predictable.
- If the model is slow, record the trace file playing back instead.
