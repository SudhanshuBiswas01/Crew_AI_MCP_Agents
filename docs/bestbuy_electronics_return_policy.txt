Best Buy Electronics Return Policy — Internal Reference

This document outlines the return windows and fees for electronic items. Standard members have a fifteen-day return window from the receipt date. My Best Buy Plus and My Best Buy Total members receive a sixty-day return window. 

Exceptions apply to activatable devices, including cell phones, tablets, cellular wearables, and mobile hotspots. These items carry a strict fourteen-day return window for all customers. Verizon devices are an exception, carrying a thirty-day return window for all customers. 

Restocking fees apply to select items. A flat forty-five dollar restocking fee is charged for cell phones. A fifteen percent restocking fee is applied to drones, cameras, and projectors. No restocking fee is charged if the item is unopened, or if the return is made in Alabama, Colorado, Hawaii, Iowa, Mississippi, Ohio, Oklahoma, or South Carolina. 

Items must be in like-new condition, containing all original packaging, accessories, and the receipt. Opened software, movies, music, and video games cannot be refunded, but can be exchanged for an identical item. Digital content and gift cards are non-returnable. Microsoft Office products have a thirty-day return window for all customers.

Returns can be processed in-store (requiring a receipt and photo ID) or online by printing a prepaid shipping label from the customer account dashboard. Customer service agents must verify the member status of the purchaser before applying restocking fees. If a customer is a Plus or Total member, ensure the correct sixty-day window is applied in the point-of-sale system.
